# Resume Website Portfolio

A static personal portfolio page presenting Jatin Ahuja's profile, skills, education, projects, and contact section.

## Built with

- HTML
- CSS
- JavaScript

## Run locally

No package installation or build step is required. Clone the repository and open `index.html` in a modern browser. If browser restrictions affect local assets, serve the folder with any simple static HTTP server.

## Project files

- `index.html` — page content and section structure
- `style.css` — layout and visual styling
- `script.js` — client-side interactions

## Notes

This is a front-end portfolio project. It does not include a server-side application or deployment configuration.
